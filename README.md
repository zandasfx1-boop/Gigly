# Gigly

**Post gigs. Get them done.**

Gigly is a worldwide marketplace where anyone can post a gig or find work: browse by country, category and budget, comment on gigs, chat directly, and build a verified profile. Members with the Monthly Pass appear as **Gigly X**.

## Features
- Post and browse gigs worldwide, with search and filters
- Comments, reactions, saved gigs and direct chat
- Blue tick verification (separate from the Monthly Pass)
- Monthly Pass with local pricing
- Admin tools: review gigs, verify members, site updates, reports
- Installable app (PWA) with a modern liquid glass design

## Stack
Static front end (`index.html`) on Vercel, with Supabase for login, database and storage.
